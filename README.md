# Cuadro de Mandos - Análisis de Vehículos

Este proyecto consiste en una aplicación web interactiva desarrollada en Python utilizando **Streamlit** y **Plotly**, diseñada para explorar y analizar un conjunto de datos de anuncios de venta de coches en EE.UU.

## Funcionalidades
La aplicación web proporciona un cuadro de mandos con las siguientes herramientas interactivas:
- **Histograma:** Permite visualizar la distribución de los vehículos según su millaje/kilometraje (`odometer`).
- **Gráfico de Dispersión:** Muestra la relación y correlación entre el kilometraje de los vehículos y su precio de venta en el mercado.

## Instrucciones para ejecutar de forma local
1. Asegúrate de tener activo tu entorno virtual.
2. Ejecuta el comando: `streamlit run app.py`
